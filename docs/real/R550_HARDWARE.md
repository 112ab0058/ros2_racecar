# WHEELTEC R550 mini AKM 硬體盤點（H0）

更新時間：2026-10-15（到貨當天，依照片與廠商頁面整理）。
規則：照片或實物確認的寫「實物」；只有廠商頁面寫的寫「廠商頁」；都沒有的寫 UNKNOWN。

## 系統一覽（規劃）

```text
Jetson Orin Nano（Ubuntu 24.04、ROS 2 Jazzy）
   ├─ USB ── C30D 控制板（STM32）── 4 顆馬達 + encoder、轉向、IMU、電池
   ├─ USB ── LSLIDAR N10P 光達（另一條 USB 只供電）
   └─ USB ── WHEELTEC C70 相機
```

## 控制板

| 項目 | 值 | 來源 |
|---|---|---|
| 型號 | **C30D**（板上絲印） | 實物 |
| 主控 | **STM32F407VET6**，FreeRTOS；韌體版本 UNKNOWN | 廠商開發手冊 |
| IMU | **ICM20948**，在控制板上 | 廠商開發手冊 |
| 板上元件 | OLED 螢幕；藍牙序列模組（標示 LEVEL 3.3V、Power 3.6–6V、腳位 STATE / RXD / TXD / GND / VCC / PWRC）；兩個藍色按鈕（USER、RESET）；三個 USB-C 孔；藍色螺絲端子（接電池紅黑線）；四組馬達接頭（MotorA–D） | 實物 |
| **馬達開關** | 板上有 **Motor OFF / ON** 撥動開關。**OFF 時馬達不會轉**，第一次通電、只讀測試都要放 OFF | 實物（絲印） |
| 三個 USB-C | 左：給樹莓派 / Jetson Nano 的 **5 V 供電**；中：**串口 3，和 ROS 主機通訊**；右：串口 1，燒錄程式 | 廠商主板詳解圖 |
| 和主機的連線 | **一條 USB 線**：Orin 的 USB-A ↔ C30D 中間的 USB-C（串口 3），底盤只需要這一條訊號線（Orin 的電源另外接）。廠商文件：主控和底盤、感測器的訊號全部走 USB。**115200 baud**；指令 11 bytes、回授 24 bytes（20 Hz），見 [R550_STUDY_NOTES.md](../research/R550_STUDY_NOTES.md) 第 7 節。USB 轉串口晶片是 **CH9102**（`lsusb`：`1a86:55d4`），Linux 內建 CDC-ACM driver，裝置 `/dev/ttyACM0`，固定名稱 `/dev/serial/by-id/usb-WCH.CN_USB_Single_Serial_0002-if00` | 廠商協定文件 + **2026-10-16 實車錄封包驗證** |
| 電源輸入 | ≤ 17 V、不可反接，建議 12 V；馬達 4 路共 ≤ 5 A | C30D 手冊 |

## 電源

| 項目 | 值 | 來源 |
|---|---|---|
| 充電器 | 鋰電池充電器，DC5525 接頭，輸出 **DC 12.6 V 1.9 A** → 推測電池是 3 串鋰電池 | 實物（充電器盒） |
| 充電口 | 車身上標「充電口」 | 實物 |
| 電池 | 實物標籤：**5100 mAh**（2026-10-18 Ray 看標籤），型號、最大放電電流 UNKNOWN（待讀標籤）。廠商文件〈MiniROS小车问题排查与改装介绍〉圖 1-3 是另一個版本（E3535、5300 mAh、最大持續放電 8 A），**不是我們這顆，不能直接套用**。輸出是盒子側面的圓形 DC 插座，車上插頭是直角 DC 頭，孔徑 2.1 / 2.5 mm 待確認。廠商：STM32 低於 10 V 不允許控制 | 實物、廠商文件 |
| Orin 原廠變壓器 | LITEON PA-1450-26：**19 V、2.37 A（45 W）**，中心正極 | 2026-10-18 照片 |
| 給 Orin 的供電 | **未解決**。C30D 的 5 V USB-C 不能用（Orin 開發套件 DC 輸入 9–20 V，NVIDIA 論壇）。傾向：電池 DC 一分二 → 保險絲 → 升壓模組 19 V → Orin。**廠商的作法：12 V 主控在電池電壓範圍內就直接從電池供電**（電池 10–12.6 V，用 T 頭線分流；廠商表格寫 Orin Nano 輸入 12 V、8–19 V）。我們的接頭和線材待確認 | 廠商〈ROS機器人電氣連接介紹〉、〈ROS主控對比〉 |
