# 2026-11-26 晚上場地：順序、要量的東西

**目的**：一次把報告要的資料錄齊：轉彎規則兩個方向、模仿學習兩個方向的示範、實驗 E1（定位融合）的起終點、E2（建圖）的場地尺寸、E4（網路對規則）。期限 12 月（Ray 11-26），之後還可以再去，但今晚盡量一次做完。

操作步驟照 [RUNBOOK](../RUNBOOK.md) 6h（啟動頁）。所有會動的都是：0.10 m/s、按住手機「自動」才動（放開 0.35 s 內停）、太近 2 cm 鎖住、Motor 開關。

## 一、出門前（家裡，約 30 分鐘）

1. 車子電池充滿（12.6 V 綠燈）；手機充電；啟動頁書籤。
2. 帶：捲尺、紙膠帶、筆、這張表（手機看）、一個能把車架空的盒子、拍影片的手機架或另一支手機。
3. 架空先測（11-26 的清單；限 0.10 m/s、180 s；放開自動／停止／Motor 開關）：
   1. 「重置」：鎖住 → 拿開東西 → 重置 → 再按住自動能動。
   2. 駕駛頁「左滿舵」「右滿舵」：前輪打到底。
   3. 「網路」能啟動、後輪會轉（架空時方向沒有意義）。
   - 右前輪角度（`orin_steer_air.sh`）不急，場地之後再量。

## 二、到場地先量（E2 的標準答案，約 15 分鐘）

量**牆的內面到內面**，單位 cm，寫在下面：

| 量什麼 | 第 1 次 | 第 2 次 |
|---|---|---|
| 場地內寬（左右）：靠上方、靠下方各一次 | | |
| 場地內長（上下）：靠左邊、靠右邊各一次 | | |
| 島的四邊長（上、下、左、右） | | |
| 島到外牆的走道寬（四邊各一次） | | |

再從正上方拍一張整個場地的照片（地圖要和它比）。

## 三、規則開（每趟約 5 分鐘）

每趟開始前**在起點貼膠帶**（E1 用），結束後量終點：

1. 車放好後，沿著**左邊兩個輪子的外側**貼一條直的紙膠帶，在左後輪、左前輪的輪胎中心各畫一條橫線。
2. 跑完（3 圈會自己停在起點附近），量：
   - 左後輪中心：沿膠帶往前多少 cm（往前為正）、離膠帶多少 cm（往外為正）。
   - 左前輪中心：同樣兩個數字。
3. 寫在表上。有撞牆鎖住、被手拿起來的那趟，終點不用量（只寫「中途動過」）。

| # | 設定 | 起點 | 目的 | 左後輪 前/外 | 左前輪 前/外 | 備註 |
|---|---|---|---|---|---|---|
| 1 | 規則、逆時針、預測式、3 圈 | 直道前段、中間 | 預測式第一次上地面、E1 | | | |
| 2 | 規則、順時針、預測式、3 圈 | 同上 | 同上 | | | |
| 3 | 規則、自動判斷方向、預測式 | 直道前段，跑逆時針 | 自動判斷方向 | | | |
| 4 | 規則、自動判斷方向、預測式 | 直道前段，跑順時針 | 同上 | | | |
| 5 | 規則、手動選逆時針、預測式 | 直道**後半段**中間 | 任意位置起跑 | | | |
| 6 | 規則、手動選順時針、預測式 | 直道後半段中間 | 同上 | | | |

- 預測式不對（打太早、太晚）→ 按停止，改「固定距離」再跑一次，備註寫下來。
- 每趟按「停止」後看啟動頁「上一次」：轉彎幾次、有沒有鎖住、**地圖有沒有存到**。

## 四、模仿學習的示範（約 30 分鐘）

1. 啟動頁「規則」開始，但**不按自動**，用駕駛頁「按鍵」自己開（這樣錄到的是人開的）。
2. 逆時針 2 圈、順時針 2 圈。
3. 每個方向各做幾次「救回來」：故意開偏、靠近一邊牆，再修回中線。
4. 上面第三節規則開的那幾趟也會變成示範資料（標成「規則」）。

## 五、訓練與網路開（E4，約 40 分鐘）

1. 啟動頁按「訓練」（約 1–2 分鐘，不會動馬達）。看結果的驗證準確率和每種動作的筆數（左打滿、右打滿都要有幾百筆以上）。
2. **先架空**：車放盒子上，駕駛選「網路」、60 s，按住自動，看前輪會左右變化。
3. 上地面：網路、逆時針方向起點、180 s；手準備隨時放開自動。再順時針一次。
4. 和第三節的規則比：完成幾圈、鎖住幾次、離牆最近多少（我回來用錄影算）。

## 六、影片（給教授、報告）

- 規則各一個方向、網路最好的一趟，從正上方或斜上方錄整個場地。

## 七、回來之後（Claude 做）

1. `bash ~/racecar_ws/tools/orin_field_report.sh`（只讀）：每一趟的圈數、鎖住、離牆最近、E1 各種定位方法的起終點誤差。
2. 地圖沒存到的那幾趟用錄影重建；E2 用地圖量場地尺寸，和第二節的捲尺比；有 EKF 和只有輪子的地圖比較。
3. 結果寫進 LOGBOOK、STATUS，PBL 第 8 份學習單。
