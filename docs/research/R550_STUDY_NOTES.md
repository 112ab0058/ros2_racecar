## 1. 整台車的分工

```text
上層決策（Orin，ROS 2）      ──下發三軸目標速度──▶   底層執行（C30D 上的 STM32）
  需要算力、實時性要求不高   ◀──回傳里程計、IMU、電壓──   算力低、實時性要求高
                                                          ├─ 運動學逆解 → 各輪目標速度
感測（光達、相機）直接接 Orin                              ├─ PI 控制 → 馬達 PWM
                                                          └─ 舵機 → 前輪轉向
```

**重點**：Orin 不直接控制馬達，只告訴 STM32「我要多快、轉多快」，剩下的由 STM32 做。（來源：開發手冊第 2、3 章）

## 3. 開機流程

1. 確認電池電壓 > 10 V，低於 10 V 要先充電（快速手冊）
2. 打開主開關，蜂鳴器短響一聲
3. **前 10 秒是初始化**：LED 快閃，STM32 在取樣 IMU 零點並去除漂移（開發手冊 2.8）。**這段時間車子不能動、不要碰**，不然 IMU 零點會偏，之後建圖會歪
4. 10 秒後 LED 變成正常閃爍，才能控制
5. OLED 左下角顯示控制模式，**開機預設是 ROS 模式**（開發手冊第 5 章）

| OLED 顯示 | 控制來源 |
|---|---|
| ROS | 串口 3（ROS 主機）← 我們要用的 |
| USART | 串口 1 |
| APP | 藍牙手機 APP |
| PS2 | PS2 手柄 |
| R-C | 航模遥控 |
| CAN | CAN 匯流排 |

**驗證**：開機後拍 OLED，確認第一行的車型是阿克曼、左下角是 ROS。

## 4. 運動學：阿克曼怎麼換算（專題報告可以直接用）

R550 mini akm 是**後輪兩顆馬達驅動、前輪用舵機轉向**。

| 符號 | 意義 |
|---|---|
| W | 輪距（左右後輪的距離） |
| L | 軸距（前後輪的距離） |
| K | 前輪兩個轉向節的距離 |
| v、ω | 車子的前進速度（m/s）、轉向角速度（rad/s） |
| v_L、v_R | 左、右後輪的速度 |
| α | 左前輪的轉角（控制量） |
| R | 轉彎半徑 |

**逆運動學**（已知要的 v、ω，求輪子要怎麼動）：
- 轉彎半徑：`R = v / ω`
- 左前輪轉角：`α = atan( L / (v/ω − K/2) )`　（式 3-3）
- 後輪速度：`v_L = v − ω·W/2`、`v_R = v + ω·W/2`　（式 3-4）

**正運動學**（已知輪子怎麼動，求車子的 v、ω，這就是里程計）：
- `v = (v_L + v_R) / 2`　（式 3-6）
- `ω = (v_R − v_L) / W`　（式 3-8）

**理想的內外輪轉角關係**：`cot β − cot α = K / L`（式 3-2）。只要控制一個前輪，另一個就跟著決定。

**推論**：
- `ω = 0` 時 R 是無限大，`α = 0`，車子直走
- `v = 0` 時公式不成立：**阿克曼不能原地旋轉**。所以我們的控制器不能依賴原地轉
- 最小轉彎半徑由最大轉角決定

**驗證**：量 W、L、K，代入公式算出最小轉彎半徑，再實際開一圈量地上的圓。

（來源：運動學 PDF 第 3 章，第 6–7 頁）

## 5. 馬達怎麼控制

**輪子線速度**（開發手冊 4.1）：

```text
線速度 = 每秒 encoder 計數 × 輪子周長 / encoder 精度
程式：MOTOR_A.Encoder = Encoder_A_pr × CONTROL_FREQUENCY × Wheel_perimeter / Encoder_precision
```

`Encoder_precision` 包含線數、減速比和倍頻。例如 500 線的 GMR encoder，AB 兩相 4 倍頻、減速比 1:30，馬達輸出軸轉一圈會數到 500 × 4 × 30 = 60000 個脈衝（這個減速比只是手冊舉的例子，R550 mini 實際的值要查程式）。

**增量式 PI 控制**（開發手冊 4.2）：

```text
誤差 = 目標速度 − 實際速度
PWM += Kp × (這次誤差 − 上次誤差) + Ki × 這次誤差
PWM 限制在 ±7200
```

「增量式」是指每次只算 PWM 要「增加多少」，而不是直接算 PWM 的值。

**驗證**：馬達 OFF、用手推車子，看 ROS 回傳的速度是否合理（第 2 階段）。

## 8. 安全守則（整理自廠商手冊）

1. **還沒測試完成前，把車架起來讓輪子懸空**（開發手冊 8.3）
2. **禁止堵轉**：輪子卡住時馬達電流會暴增，會燒壞驅動晶片
3. 電源不能超過 17 V、不能反接
4. 板子不能放在金屬表面上，碰板子前先摸接地的金屬放靜電
5. **燒錄程式時不要拔插 USB**，不要改串口晶片的設定
6. 不用時充電口要蓋起來
